# Turbo Rush

A neon-themed browser racing game built with HTML, CSS, and JavaScript.

## Run locally

1. Open the project folder in a browser, or serve it through a local web server.
2. Example:

```bash
python -m http.server 8000
```

3. Visit:

```text
http://localhost:8000
```

## Controls

- Left / Right Arrow or A / D: steer the car
- Space: nitro boost
- P: pause/resume
- Mobile buttons: available on touch devices

## Features

- Neon racing UI
- Score, speed, level, and lives HUD
- Nitro bar and combo system
- Enemies, hazards, and collectible powerups
- Pause and game-over screens
- Best score saved in local storage
