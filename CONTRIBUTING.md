# Contributing to Turbo Rush

Thank you for your interest in contributing! Here's how you can help:

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/turbo-rush-game.git`
3. Create a new branch: `git checkout -b feature/your-feature-name`

## Development

The game runs on vanilla HTML, CSS, and JavaScript. No build tools needed!

### Local Setup
```bash
python -m http.server 8000
# or
npx http-server
```
Then visit `http://localhost:8000`

## Code Style

- Use 2-space indentation
- Use meaningful variable names
- Keep functions small and focused
- Add comments for complex logic

## Areas to Contribute

- 🎮 **Gameplay**: New powerups, difficulty tweaks, features
- 🎨 **Visual**: UI improvements, animations, effects
- 🚀 **Performance**: Optimizations, bug fixes
- 📚 **Documentation**: Guides, tutorials, examples
- ♿ **Accessibility**: ARIA labels, keyboard navigation improvements

## Submitting Changes

1. Make your changes
2. Test thoroughly
3. Commit with clear messages: `git commit -m "Add: description"`
4. Push to your fork: `git push origin feature/your-feature-name`
5. Open a Pull Request with a detailed description

## Pull Request Guidelines

- One feature per PR
- Include before/after if visual changes
- Update README if needed
- No breaking changes without discussion

## Questions?

Open an issue or start a discussion! We're here to help.

Happy coding! 🚀
